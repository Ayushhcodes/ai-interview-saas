# AI Interview SaaS

## 1. What is this project?

An AI-powered interview preparation platform where users can upload their resume
and practice technical/HR interviews with AI-generated questions and feedback.

## 2. Main Goal

Build a full-stack AI interview platform using the MERN stack and understand
how every major part of the application works.

## 3. Tech Stack

### Frontend

- React
- Vite
- Tailwind CSS
- Redux
- Axios
- Framer Motion

### Backend

- Node.js
- Express.js
- MongoDB
- Mongoose

### Authentication

- Firebase Google Authentication
- JWT

### AI

- OpenRouter / AI API

### Other

- Multer
- Razorpay
- Render

## 4. Basic App Flow

User
→ Login
→ Upload Resume
→ AI analyzes Resume
→ Interview Questions Generated
→ User Answers Questions
→ AI evaluates answers
→ Interview Report
→ User can view interview history
